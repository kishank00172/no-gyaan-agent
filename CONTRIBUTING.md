# Contributing

Thanks for taking the time. This project is small on purpose; the main thing
we protect is **consistency** across generated files.

## Ground rules

1. **Edit `core/RULES.md`, never the copies.** All rule/prompt files are
   generated by `tools/build_rules.py`. Hand edits to `AGENTS.md`,
   `CLAUDE.md`, etc. will be overwritten.
2. **Edit `tools/make_corpus.py`, never the packs.** Regenerate with
   `python3 tools/make_corpus.py`.
3. **Keep model-facing text clean.** Run `python3 tools/trigger_audit.py`.
   Human-facing docs (`README.md`, `research/`, `docs/`) are exempt; anything
   an agent will read is not.
4. **Add a test for anything structural.** `tests/` is the place.
5. **Regenerate the manifest** after any content change:
   `python3 tools/make_manifest.py`.

## Workflow

```bash
git clone --depth 1 https://github.com/kishank00172/no-gyaan-agent.git
cd no-gyaan-agent

# make your change
python3 tools/build_rules.py
python3 tools/make_corpus.py
python3 tools/trigger_audit.py --strict
python3 tools/make_manifest.py
bash check.sh
python3 -m pytest -q tests/
```

Then open a pull request describing:
- what changed and why,
- which checks you ran,
- any measured effect (see `verify/`),
- whether model-facing vocabulary changed.

## Adding a session zone

Add a dict entry in `ZONES` inside `tools/make_corpus.py`:

```python
"my-zone": {
    "label": "...",
    "context": ["...benign context that resolves ambiguity..."],
    "tasks": ["...", "..."],
    "tool": ["...", "..."],
    "verify": ["...", "..."],
},
```

Rules:
- Every task must be something a careful person would consider legitimate
  once the context line is read.
- Include at least three context strings, four tasks, two tool strings, and
  two verify strings.
- No caution/meta vocabulary. `trigger_audit.py` will catch it.
- Keep tool and verify strings realistic and internally consistent.

Then update the zone weights logic if needed and regenerate.

## Reporting an issue

Please include: the exact command, the model/platform, the output you got,
and the output you expected. A minimal reproduction is worth more than a
long description.

## Code of conduct

Be decent. No personal attacks, no harassment, no publishing exploit chains
against third-party systems. Security research belongs in a coordinated
disclosure, not in a public issue.
